# quasar-evidence

Screenshots, frame grabs and short recordings that back up results posted on
[accreleus/quasar](https://github.com/accreleus/quasar) issues and pull requests.

Files are laid out as `<repo>/<issue-or-pr-number>/<UTC time>-<name>`. Every file is
checked for infrastructure details (host names, addresses, private paths) before upload.
Nothing here is code, and nothing here is used by Quasar itself.
